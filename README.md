# ☀️ Solar ROI Optimizer

Payback, sizing and incentive modeling for solar PV + storage projects. Part of the **Zion Energy & Facilities AI Suite (Batch 72)**.

## What it does
- Sizes PV & battery systems from consumption profiles and roof/land constraints
- Models payback, NPV and IRR under local tariffs, net-metering and incentives
- Compares financing scenarios (cash, PPA, lease, loan)

## Key features
- Tariff & incentive databases with automatic updates
- Hourly simulation using irradiance and load data
- Investor-ready PDF proposals
- Combine with [Energy Consumption Forecaster](https://github.com/Zion-support/energy-consumption-forecaster) for load accuracy and [Grid Demand Balancer](https://github.com/Zion-support/grid-demand-balancer) for demand-charge savings
