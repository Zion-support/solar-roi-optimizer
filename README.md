## What it does
Sizes PV & battery systems from consumption profiles and roof/land constraints; models payback, NPV and IRR under local tariffs, net-metering and incentives; compares financing scenarios (cash, PPA, lease, loan); investor-ready PDF proposals. Combine with [Energy Consumption Forecaster](https://github.com/Zion-support/energy-consumption-forecaster) for load accuracy and [Grid Demand Balancer](https://github.com/Zion-support/grid-demand-balancer) for demand-charge savings.

## Key features
- Tariff & incentive databases with automatic updates
- Hourly simulation using irradiance and load data
- API + CSV connectors, dashboards, scheduled reports
